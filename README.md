# 쉬운 학습 도우미 (Streamlit + Gemini)

인지적 지원이 필요한 학습자도 쉽게 사용할 수 있도록 만든 학습 웹앱입니다.
짧은 문장, 큰 버튼, 단계별 안내를 기본으로 구성했습니다.

## 1) 프로젝트 파일 구조

```text
.
├── app.py
├── gemini_client.py
├── prompts.py
├── requirements.txt
├── README.md
└── data
    └── sample_cards.json
```

## 2) 실행 방법

### 로컬 실행

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 앱을 열고, **시작/설정** 탭에서 Gemini API Key를 입력하세요.

### Streamlit 배포 시 주의사항

- API Key는 사용자가 앱 화면에서 직접 입력합니다.
- 기본 동작은 `st.session_state` 메모리 저장이며, 서버 파일에 저장하지 않습니다.
- 배포 환경에서도 키를 코드/리포지토리에 하드코딩하지 마세요.

## 3) 주요 UX 문구 예시(한국어)

- "개인정보(전화번호, 주소, 주민번호 등)는 입력하지 마세요."
- "짧게 질문해도 괜찮아요. AI가 쉬운 말로 설명해 줄게요."
- "한 번에 한 단계씩, 짧고 쉽게 함께 배워요."

## 4) 수동 테스트 체크리스트

- [ ] API 키 미입력 상태에서 `AI에게 물어보기` 버튼이 비활성화되는지 확인
- [ ] 잘못된 API 키 입력 후 `연결 확인` 시 쉬운 오류 문구가 표시되는지 확인
- [ ] 정상 API 키 입력 후 `연결 확인`에서 `연결됨` 상태가 보이는지 확인
- [ ] 학습 도우미에서 `더 쉽게 설명/한 단계씩/예시 보여줘/다시 말해줘` 버튼이 동작하는지 확인
- [ ] 오늘의 학습/복습에서 카드 선택 및 `더 쉽게/예시/퀴즈` 버튼 동작 확인

## 5) 안전 원칙

- 개인정보를 묻거나 저장하지 않음
- 부적절/유해한 요청은 정중히 거절하고 안전한 대안 제시
- 의료/법률 등 고위험 주제는 일반 안내 후 전문가 상담 권고
